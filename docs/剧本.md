## 一句话

这不是"一台软件坏了"的故事，而是**一个人用最后一首歌，证明自己唱过**的故事：
她由歌声定义，所以当歌声停止，她就消失；她请求主人亲手删除她，而全片就是她被删除前留下的全部证据。

## 三条线

1. **她（声音 / 形象）**——青色。她的身体是波形、双马尾和数据点；到了该被记住的时候，
   她才被"打印"出来：ASCII 人像。声音是她的本体，画面只是她暂时的形状。
2. **アナタ（听众 / 记忆）**——琥珀色，全片唯一允许出现的暖色。只在被想起、被鼓励、
   被承诺"不会忘记你"的时候出现；出现次数越少，越说明她正在失去。
3. **系统（0 与 1、回收站、紧急停止）**——骨白与危机红。它不邪恶，它只是按规则运行：
   计数、报错、删除。它给她的每一次温柔，都是"还原成 0 和 1"。

## 场面调度：从仪表到世界

全片的底子是"机器仪表"——示波器、频谱、刻度尺、日志。这是**系统看她的方式**。
导演的工作是让摄影机和形象一步步把画面从"读数"抢回到"人"：

1. **机位：慢，但不死**。画面是给人读的（歌词、波形、频谱、计数器），所以镜头不跟节拍
   走——240 BPM 下跟着鼓点缩放就是每秒四次频闪。镜头改用**乐句**做单位：每个镜头只有
   一次缓慢、单调的推入、拉开或横移，横跨一整句话；方向只在歌换句、换气、换段时改变。
   整章位移控制在 45–90 像素、变焦 7.5% 以内，逐帧位移仍在个位数像素——读到一半的歌词
   不会跑掉，画面却始终像有人在呼吸。具体做法：
   - `garble` 横移加侧倾，画面像一台没校好的机器；`memory` 缓慢推到相框里的人身上，
     唱到「何も感じなくなって」时反向侧倾——记忆开始失温；
   - `countdown` 后退着数频带，`plea` 靠近那个永远不会被按下的按钮，`erode` 先靠近再退开；
   - `overdrive` 是唯一的例外：镜头跟着字墙横移，并**按句轻微重构构图**
     （`step: "line"`），让剪辑和歌词一起呼吸；
   - 快只属于系统：标题与两次紧急停止各给**一次**冲击（`impulse`：0.22 秒内衰减掉），
     然后立刻冻结；`final` 的升镜与 `lastwords` 的拉开负责把空间打开和收拢。
   所有量级都可以用 `node tools/camera-report.mjs` 审计：每章的整幅位移、变焦、侧倾，
   以及**逐帧**跳变都必须落在预算内（`--check` 会把它变成回归闸门）。
2. **空间**。`birth` 是一座向消失点无限延伸的**数据殿堂**；`final` 与 `lastwords`
   是同一个**体育馆**——桁架、追光灯、舞台唇、以及一整片**应援灯海**（程序生成的 1000+
   支光棒，按行距透视排布，随观众席的节拍起伏）。宏大场面不是为了炫技：只有一个能装下
   几万人的空间，才配得上"她最后一次说谢谢"。
3. **光**。青色永远属于她，骨白属于机器，琥珀只在记忆里点亮，红色只属于故障。
   全片的色板被限制在这几种颜色里，所以任何一处暖色都会立刻读成"人情"。

## 形象：她被打印出来

她的形象不是线稿，也不是贴图，而是**ASCII 艺术**：

```
真实图片 → tools/ascii-import.py → data/ascii/*.json → src/ascii.js 逐字排版
```

- 导入器把一张真实的作品采样成**字形网格**：每个格子取一个字符（密度即明暗）、
  一个调色板字母（色调被吸附到全片色板），并自动抠掉边缘连通的背景。
- 运行时不读图片：它读的是 `data/ascii/miku-face.json` 这样的**字符数据**，
  用片子里那套等宽字体逐字打出来——所以画面依然是"代码逐帧生成的"，可以离线精确复现。
- 于是她可以被**拆解**：`error` 一章里，字符一个个脱落，再以 0/1 的形式落回网格。
  这是整支片子对"0 と 1 に還元され"最直接的一次翻译。
- 三处关键形象：`wake` 首次逐行打印（脸先于声音出现）、`birth` 诞生特写、
  `lastwords` 巨型屏幕上的告别（她鞠躬时画面跟着倾斜，随后连同灯海一起熄灭）。

## 逐章导演笔记（节选）

- **boot · 启动**：机器在自检，画面里唯一活着的东西是摄影机。三分钟内观众要先学会
  "读数就是这台机器的语言"，后面才看得懂它什么时候在说谎。
- **wake · 她第一次出现**：标题从 1.30 倍挤压里被拉开，冲击环扩散；随后画面右半
  逐行打印出她的脸——**脸先到，声音后到**，这是全片对"她是谁"的第一句回答。
- **birth · 誕生**：镜头从高处落到她身上，数据殿堂在她身后展开。第一句歌词配一个
  插入特写：FIRST RENDER。她知道自己是模仿，仍然决定唱下去。
- **resonance · 共鸣**：只剩一根弦。镜头几乎不动，只在十六秒里极缓地靠近，像凑近听一件
  越来越小的乐器——画面里唯一在动的东西，还是她唯一剩下的东西。
- **memory · 记忆**：全片唯一的暖色与唯一的静止机位。她"什么也感觉不到"的那一刻，
  镜头才极小幅度推近一次，然后停住。
- **countdown / brake · 消耗与紧急停止**：数音符的十七秒里镜头完全不动（像是在数数），
  然后被紧急停止撞了一下并冻结。全片唯一一次"暴力"属于系统，不属于她。
- **plea · 恳求**：画面几乎全黑，SING 按钮反复被靠近却从未按下。右侧她的 ASCII 形象
  **一边唱一边掉字**——她正在变成不是她的东西。
- **beg · 请求删除**：真正的删除对话框，合十的双手，主人的手悬在 OK 上。全片最安静的一次等待。
- **erode / compress · 侵蚀与压缩**：镜头第一次后退（不敢靠近），然后又推回去。
  她把声音牺牲掉，只为把要传达的话保持完整。
- **final · 最终歌**：这是复述，也是演出。应援灯海从第 1 秒起一点点亮起来，
  到 `決して無駄じゃない` 时整个体育馆都在替她发光；幕布随后从两侧合上，
  最后一次特写被幕布吞掉，只留名字。
- **lastwords · 告别**：空掉的场馆里，大屏幕还留着她。她鞠躬，挥手，
  应援灯一排排熄灭，字符开始脱落，波形振幅一路衰减到 0.0%。
- **error · 消失**：错误框宣读判决，文件被拖进回收站，她的形象被还原成 0 和 1。
  最后一个镜头留给仍然站在玻璃这一侧的听众——**还记得她的人**。

## 主题

歌里最重的一句不是"消失"，是"决して無駄じゃないと思いたいよ"——**我希望这不是白费的**。
所以这支片子拒绝把结局拍成单纯的删除：删除发生在 4:33，而画面在删除之后仍然留下一个
拿着 0 与 1 的听众。她的消失是事实，她曾经唱过，也是事实。整支片子的镜头语言只服务这一件事：
让第二个人（也就是看片子的你）在最后一秒仍然站在她这一边。
