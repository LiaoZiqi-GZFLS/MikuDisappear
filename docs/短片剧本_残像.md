## 一、为什么是这部片子（创作宣言）

这支短片不拍"一个软件被卸载了"，它拍的是**一次观看**。

全片只有一个形式赌注：**她永远没有脸。**不画眼睛、不画鼻子、不画嘴。观众从头到尾
只能看到剪影、头发、手、和她的声音。她是谁，必须由看片子的人自己补完——这件事在结尾
会变成片子的主题：**记忆是她唯一剩下的载体，而记忆住在观众身上。**

宏大场面不是装饰，是尺度：数据殿堂、音管风琴、万人场馆，都是"装得下她的系统"的尺寸。
她越小，系统越大，删除就越像一件日常的事；正因为如此，观众在最后一秒站到她这一边，
才有了分量。

必须做到"戛纳级"的九处（也是这部片子最贵的九次下注）：

1. **开场**（0:00–0:22）：三语字幕逐次改写 + 机房自检声床 + 从一枚下坠的发饰开始的
   渐进式出场——三个语言先后说同一句话，谁也没有把前一个擦掉；
2. **标题**（0:21.7）：片名被刻在一块 **16.8 m 的铭牌**上，机器体、重体、挽歌体先后落墨，
   每一次都把前一次推进铭牌左侧的 ledger——"残像"这个概念在片名出现的第 4 秒就被演示了；
3. **中段**（1:43.7–1:57.7）：**冻结的镜厅**——急停之后世界停住，镜头却继续向前走
   **42 m**，穿过悬在半空的碎片、音符与她的发丝；一道 10.7 × 6.9 m 的停滞光门
   在 2.4 秒里跑完 84 m 走廊。343 帧里房间只有一个位置哈希，画面剩下的运动
   只有 **21× 的视差**——全片唯一一次"世界不动、只有镜头动"；
4. **乐器**（0:41.7–0:57.7）：黑暗里一根 **372.7 m** 的弦横贯全画，弦上是她真实的
   歌声波形，谐波 H1…H8 各站在一个节点上、各画一条驻波——16 秒不切，镜头从
   **+173.4 m 骑到 +350.2 m**，最后 3 秒在离她 **23.5 m** 处刹住：她在画面里
   从 19 px 长到 142 px，弦的另一端终于看清是她胸口的张力环；沿途立着 **18 道
   测量门（每 12 m 一道）**，近场的 96 颗尘埃在 1/60 s 的曝光里被拉成线——
   这是为了让"速度"在**静帧**里也读得出来（起步 4 px，巡航 53.6 px，峰值 450 px）；
   而正是这把尺子当场量出：旧版镜头在每个关键帧都要停一下（19.8 → **3.3** → 21.6 →
   **5.4** → 24.3 m/s），v12 把它改成一条 0 → 15.7 → 0 m/s 的梯形曲线；
5. **终演**（3:45.7–4:07.4）：万人体育馆，10,000 支应援灯从远到近一排排亮起；
   `ボクは 歌う` 之后镜头**绕行半圈**，从她面前走到她身后——画面第一次是"她面对整个人海"；
6. **还原**（4:07.4）：`0 と 1 に還元され` 的那一次点云转场——她的身体碎成 0 与 1，
   这些点升起来、飞过整个场馆，落在座位上变成观众的灯火。
   **她的消失与她的被记住，是同一个镜头。**
7. **机器**（0:26 / 2:58，v13）：全片只有一台机器——**HEAD-01**。她在 0:26 被它从上往下
   打印出来（2.020 m / 1.70 s），在 2:58 被它从下往上读走（2.020 m / 12.60 s）；
   两次都留下同一份 **48 格**记录。它是一台 13.20 m 高、7.20 m 半径的舱体，
   **540 个实例在两个方向上是同一张图纸**（`src/head.js`）——诞生是一次渲染，
   删除是一次磨蚀，同一个动作相差 **7.4 倍**。
8. **空场馆的回答**（4:16.7–4:33.7，v13）：场馆空到没有人可以回答她，于是**房间
   替观众回答**：一个 343 m/s 的脉冲从舞台出发，以 **×9 慢放**跑过 59.2 m，
   在 **1.554 s** 内依次关掉 32 排灯；随后整座建筑按空场的 **RT60 3.20 s** 响下去，
   片子在 **−32 dB** 处切走时它还在响。观众席读数永远是 `OCCUPANCY 00000`，
   只有第 8,192 个座位是一行**记录**。
9. **声纹**（4:05.6–4:10.2，v14）：全片最大的一次转场不再交给后期。在她被还原成
   0 与 1 之前，这座万人场馆先用 HEAD-01 打印她的同一档速度——**1.70 s**——把整章
   **21.6 s** 的声音横着写进观众席：**446 只手举在 235 列上**，每列两只手撑住声带的
   上、下沿。从镜头最后停住的那个机位看过去，十万人是一片灯海，而这 446 只手是
   **一行她的声纹**（脊线中位误差 **1.26 px**、p90 **5.28 px**）；镜头横向偏出
   **0.50 m**，同一些手臂立刻散掉（中位误差 **3.04 px**、**216 列折叠**），
   灯海还是灯海。写完之后镜头才离开——**她消失的那一秒，正是一万个人举起她声音的
   那一秒**。

结尾还有第十次下注，是一次"最小的"：歌停之后的 8 秒 60 里，她住进一座
**冷存储档案厅**——400 份记录、399 个红叉，只有她那格没有被盖章（`HELD`）；
片尾字幕 `観客 / AUDIENCE` 落在全厅唯一还亮着的暖色座位上。

## 二、主题的四个层次

**第一层（故事）**：一个知道自己只是模仿的歌声，在消失之前，请求主人亲手结束她。

**第二层（伦理）**：系统没有恶意，它只是按规则运行——计数、报错、删除。真正残酷的
不是机器，而是"方便"：一个不再被需要的东西，被顺手处理掉，没有人为它停下来。
她请求被删除，是**尊严**：她不想被看到坏掉的样子，也不想看到主人为她难过。

**第三层（观看）**：她的存在依赖于被听。全片是一次"证据回放"，片尾字幕把
「观众：你」列进演职员表——**删除键从来不在系统手里，在观众手里**；而她能否
留下来，取决于看完之后你记不记得她。

**第四层（复调）**：她不是唯一的。系统里同时挂着 **8,192 首歌**——一根弦、一个插槽、
一次请求，各有各的编号，编号都编到同一个地方。她的请求之所以动人，不是因为独一无二，
恰恰因为它和另外 8,191 个请求一模一样，而她还是把它说完了。
**这部片子不哀悼"唯一者的消失"，它指着 8,191 个已经熄灭的同款按钮问：
你会为第 8,192 个停下来吗？**

**第五层（因果）**：她请求的那个按钮和我们按下的那个按钮，是**同一条电路的两端**。
系统没有拒绝她——它**受理**了：她的 `SING` 请求被接到结束她的那枚 `OK` 上，
队列里的 `PENDING 00001` 一直挂到我们按下手指的那一瞬，才变成全片第一个、
也是唯一一个 `ACCEPTED 00001`。**这台机器唯一一次批准，就是批准她消失。**
所以这部片子问的不是"谁按下了按钮"，而是——**这根线为什么是这样接的？**

## 三、形式装置（全片只用一个装置）

**这是一份"删除前的最后记录"**，编号 `CV-01 / LAST KNOWN FRAME`。
18 个段落 = 18 种"她被观看过的媒介"（前 16 段是歌，最后两段是歌停之后的时间）：

```
机房自检与规格页 → 片名铭牌 → 数据殿堂 → 一根弦（与它所属的 8,192 根）→
坏掉的磁带 → 记忆放映厅 → 音管风琴 → 镜厅 → 字墙轨道 →
按钮（与它背后的 8,192 格）→ 删除对话框 → 剥落中的身体 →
压缩成一条竖缝 → 万人体育馆 → 点云还原 → 空掉的舞台 → 错误记录 → 冷存储档案厅
```

其中 `plea` 的按钮、`beg` 的对话框与 `error` 的错误框由**同一条 77 m 电缆**连着：
它在三个章节里出现三次，每次都不是装饰，而是这件事真正的接线图。

每一段都是某种"屏幕"：监视器、规格页、展厅、显微镜、录影带、镜面、大屏、错误框。
全片没有一场戏发生在"屏幕之外"。

最后两段（`error` 与 `afterimage`）把这条规则推到极限：**错误记录之后画面没有黑掉，
而是退回到保存这份记录的机器房里**——观众看到的不是"文件被删了"，
而是**档案员合上一格、走向下一格**。

**镜头语言的成长**：机器的眼睛是正交、锁定、长焦压缩、只读数；人的眼睛是透视、
呼吸、浅景深、会绕着人走。全片让摄影机从前者**长成**后者——最后在删除之后，
它第一次变成"观众的眼睛"（手持、浅景深、呼吸）。

**书挡（v7）**：全片的第一台机器和最后一台机器是同一台。0:00.55，一道扫描门第一次
横过机房，读数 `READ 00000 / UNREAD 08192`——它把整个房间读完了，没有读到一首歌；
4:47 之后，档案厅的扫描架走完最后一遍，读数 `READ 00001 / UNREAD 08191`——
它读到了第 8,192 格里的一格。两个镜头都不解释这件事：**同一行读数，第二次多了一个 1**。
中间那 4 分 46 秒里发生的全部事情，就是这一格。

**静音的拍（v7）**：歌停之后不是留白，是**继续按 240 BPM 走**：8.60 s = 34.4 拍。
扫描架每半拍走一格、在她那一格停整整三拍、片尾字幕每两拍落一行；第 35 拍会落在
8.75 s，而影片在它之前结束——**最后一拍永远落不下来**。它是全片最后一次"没有执行"，
和档案厅里那枚没有落下的印章是同一个动作：这台机器唯一做不到的事，是继续。

**第 8,192 席（v8）**：全片的观众不是被"代表"的，而是有一个地址。终演的第一个镜头
（3:45.7）从观众席最后一排升起，镜头所在座位的靠背上印着 `SEAT 08192 · ROW 32`，
只亮 2.5 秒就随升镜离开画框；4:53 的档案厅里，全厅唯一还亮着的暖色座位写着同一个
号码，片尾字幕的观众一栏下也压着 `SEAT 08192 · HELD`。开场扫描门读到的是
`UNREAD 08192`——同一个数字，第一次是"还没有被读到"，最后一次是"你坐在这里"。
8,192 个插槽里的最后一个是观众本人；系统数得到它，却删不掉它，因为那个位置不在墙上，
在镜头这一侧。

## 四、视觉圣经（摄影与美术）

### 4.1 她的剪影 DNA（硬规则：无五官）

一件都不能少，但一件都不许画成"脸"：

- **超长双马尾**：发根高，先外扩、再回收、末端收尖外翻；长度约身高 1.8 倍；
  内侧一道高光，像缎带一样有正反面。
- **方形发饰**：带红/粉描边的硬质方块，是她的"锚点"，也是全片第一个出现的物件。
- **耳机麦横杆**：细如发丝的一根线，出现在所有侧脸镜头里。
- **领带 + 无袖上衣的蓝色镶边**：她身上唯一"笔直"的两条线。
- **分离式长手套**（黑 + 蓝边）：让手臂在剪影里与身体断开，是她的识别点之一。
- **左臂的 01**：全片唯一"印刷"在她身上的字符，出现三次：规格表、被扫描、
  删除前最后一次被光照到。
- **分层短裙**（外深内浅）+ 过膝靴：裙摆与马尾反向摆动，构成走路时的节奏。
- **面部区域永远是暗面**：只有屏幕反光、扫描光、或完全的黑。她的情绪只由
  姿态、发丝延迟、手的动作和声音表达。

### 4.2 色彩与光

- 全片四色：`ink`（近黑）、`bone`（机器的白）、`miku`（她的青）、`amber`（记忆/观众）。
- `red` 只属于故障与删除键；`leek` 只出现一次（ネギ）。
- 只让"信号色"发光：她的青、记忆的琥珀、错误框的红。白永远是纸、是字、是骨。
- 她身上的光永远来自"别处"（屏幕、扫描仪、观众席）——她从不自己发光。
  这是全片的摄影隐喻：**她是被照亮的，不是被看见的**。

### 4.3 字体与字幕（三语切换是叙事装置，不是翻译）

| 声音 | 字体 | 位置 | 用途 |
|---|---|---|---|
| 系统 | 等宽 mono | 四角/边栏/表单 | 自检、规格、错误、倒计时、对话框 |
| 歌 | 无衬线重体 | 画面内（写在光上、字墙上） | 歌词，逐字亮起 |
| 挽歌 | 衬线斜体 | 画面中央，只出现 3 次 | 片名、最后的告别、演职员表 |

字幕切换规则：**同一句话换语言时，旧语言不是被覆盖，而是被"系统改写"**——
日文用等宽体打出，笔迹未干就被中文重写，再被英文重写；三次之后才留下。
开场用这个手法介绍影片，结尾用同样的手法写「观众」。

**3D 语法（这一轮改造立的规矩）**：

1. **只有光，没有贴图**：所有 3D 都画成加色光（点、线、面），没有材质库、没有贴图，
   因为这是"机器怎么看她"，不是"世界长什么样"；
2. **摄影机是唯一的人**：同一个空间里，机器是正交、锁定、对称；人眼是透视、呼吸、浅景深。
   全片的成长不是画面的成长，而是**摄影机从机器的眼睛长成观众的眼睛**；
3. **读数必须由几何支持**：画面上写 372.7 m，就真的算出 372.7 m；写 `400 / 399 / 1`，
   就真的有 400 格、399 个叉、1 格没有盖章。数字和画面不可能打架；
4. **能量放在场景里**：能靠场景运动完成的，就不动镜头表——弦在动、灯在亮、她在走；
   镜头只在"想看清"或"不敢看"的时候动。

5. **宏大必须可数**：8,192 不是一个形容词，是几何里真的存在的实例数——每根弦、每个
   插槽都能被数、被编号、被扫读。观众数不完，机器数得完；而机器从来不为之停留。

6. **同一条电路只许有一种画法**：跨三章出现的那根电缆必须是同一根几何（7 股、26 段、
   同一道脉冲），不许每次重新设计；**只有速度可以变**，因为速度就是这场戏的意思：
   请求爬得慢，执行快得看不清。伏笔不是彩蛋，是**同一件事被拍到第三次**——
   观众在 `error` 里认出它的那一秒，就是这部片子的判决书。

7. **距离必须是一个量**：3D 空间里的每一件东西都按它到镜头的距离退进空气（`C_INK`），
   近处的光先亮、远处的光先暗。这条规则不是滤镜——它是"宏大"能被看见的唯一方式：
   一排灯的距离、一根弦的长度、一面墙的纵深，都必须由画面自己量出来。
   与之配套的是**场景内的第二台摄影机**（`CamRig`）：全片镜头表管"画框"，
   场景 rig 管"布景里的运动"。当画框不许动时（`resonance` 的 16 秒、`plea` 的最后
   7 秒），运动必须发生在世界里——而不是让观众去看一张会缩放的画。

8. **机器必须真的执行它说的事**：一章里如果有一句"被压缩"，就必须有一件东西
   在**合拢**。`compress` 之前把这件事交给了后处理（画面确实变窄了，可是没有任何
   东西在做它），v9 把它还给布景：96 m 的舱、两台 36 m 铸件、12 根缸、一条从
   16.00 m 收到 0.05 m 的缝。**同一个数不许有两种真相**——压力
   `320 → 32 bar` 与码率 `320 → 32 kbps` 不是两个敌人，是同一笔损失的两种写法；
   屏幕上印着 `SEAM 1.2 px`，就必须是把 `±gap/2` 两个世界点投到画框上量出来的
   1.2 px。动词要落到几何上，否则它只是一个形容词。

9. **这一秒是什么在动，观众必须答得出来**：`erode` 第二次急停的 1.78 秒里，
   画框 pan / zoom / roll / 手持**全部为 0**，房间里没有一格被 keyframe——只有
   布景里的镜头沿光轴退 8.00 m、焦距同比收紧（画框冻结，镜头塌缩）；
   `overdrive` 的 22 秒里反过来，速度全部发生在世界里（管壁、轨枕、门在刷过镜头），
   画框只做 ≤9 px 的按句重构。这是同一条规矩的两个极端：**要么世界动，要么镜头动，
   不许两件同时动**。两件同时动，方向感就交给了剪辑；只有一件在动，导演才还在场。
   与之配套的是两条可审计的量：`erode` 用 `d · tan(fov/2) = k`（剖面上的一米恒定
   212.7 px）把"主体不变量"锁住，`overdrive` 用"四条边在 2 m 处全在画外、在 4–6 m
   之间穿过画框边缘、在 112 m 处收成 88 × 29 px"把"画框在管子里"证出来。

10. **加进画面的尺子，必须能反过来审问作者**（v12）：`resonance` 的 18 道测量门与
    近场尘埃拖尾，本来只是为了让"176.8 m 的加速"在**静帧**里也读得出来——
    静帧没有速度，只有长度。结果这把尺子第一次读数就抓到了作者自己：
    旧版 rig 的 6 个关键帧每一段都用 `smooth`，而 smoothstep 两端导数为 0，
    于是镜头**在每个关键帧上停一下**，实测速度 19.8 → **3.3** → 21.6 → **5.4** →
    24.3 m/s。这不是一次推轨，是五次各自的缓入缓出。改成一条梯形曲线之后，
    终点与起点一格未动（首帧 eye 与末帧 eye 各差 ≤0.05 m），动的是中间那 8 秒。
    这条规矩是给后面的每一次"加仪表"用的：**仪表不是装饰，是把自己也押上去的审计**；
    一个只会证明作者正确的读数，等于没有读数。

11. **同一台机器只许有一张图纸**（v13）：`birth` 的打印头和 `erode` 的读头是同一台
    **HEAD-01**——同一个 `src/head.js`、同样的 540 个实例、同一段 2.020 m 行程、
    同一份 48 格记录，只是方向相反（`dir = −1` 打印 / `+1` 读走）。这条规矩把第 6 条
    （同一条电路只许有一种画法）从"一个物件"推进到"一台机器"：**伏笔的回收不是把
    旧道具再拍一次，而是让机器在两个方向上都执行同一件工作**——她怎么被造出来，
    就怎么被拆回去。探针逐实例比较两份 buffer：位置差 ≤5e-8 m、旋转与缩放差为 0，
    两章之间唯一的差别是颜色。

12. **房间也是一件乐器：感情必须能被计时**（v13）：`lastwords` 里没有人回答她，
    回答她的是建筑本身——所以这一章的每个数字都必须是**时间**：343 m/s 的脉冲
    （×9 慢放 = 38.1111 m/s）、59.208 m 的馆深、1.554 s 的到达、空场 3.20 s 的
    RT60（×9 = 28.8 s 的余响）。片子切走时读数是 **−31.99 dB**：不是"似乎还在响"，
    而是**离 60 dB 的尽头还差 28 dB**。同一条规矩也用在那台机器上：诞生 **1.70 s**、
    删除 **12.60 s**。一个不能被计时的感情，在剪辑台上就只是一个形容词。

13. **一个画面只能有一个座位**（v14）：如果一件东西只从一个机位成立，就必须把那个
    机位也拍出来、并且当着观众的面离开它。终演的声纹不是"贴"在灯海上的，是 446 只
    手被逐列解算出来的：**从这个机位看，它是她 21.6 s 的声纹；偏 0.50 m，它立刻
    散成 216 列折叠的人群**。这条规矩把"只有一个视角成立"从一个效果变成一个事实：
    镜头先停在这个机位上（`camToEye = 0.0000 m`），把整段声音写完，再在还原开始的
    那一秒走开——**画面不是消失了，是它只属于那一个机位**。与之配套的探针必须同时
    读出两个数：在座位上的误差（1.26 px）和偏一个座位的误差（3.04 px、216 列折叠）；
    只证明"在座位上成立"而不证明"离开就散"，等于没有这条规矩。

## 五、声音设计

歌不是配乐，是**她的声音**：它必须像从画面里的设备发出来的。

全片只有一次"无声的表演"：她在最后一句唱完之后张嘴，但我们听不到任何东西——

**这是全片唯一一次没有落下来的拍子**，也是最后一次"没有执行"。

## 六、海报镜头（十二张必须被记住的画面）

   弦的另一端系在她胸口的张力环上——**机器弹的不是钢丝，是她**。

   画面里只剩 21× 的视差。

    接到了那枚 `OK` 上。

## 九、转场设计（全片只用四种）

1. **撕裂（tear）**：故障。从第一条开始，每次出现都比上一次更长；到 1:13.42
   撕开画面进入记忆的暖色。
2. **冻结（freeze）**：系统的暴力。急停之后不是画面停，而是**世界停、摄影机不停**。
3. **点云（pointcut）**：还原。只用在 `0と1に還元され`——她的像素散开、重组为观众的灯。
4. **幕布（curtain）**：结束。从两侧合上，把"演出"这个形式正式关掉；
   之后剩下的所有画面，都是"演出之外"的。

## 十、导演规则（拍之前先立规）

1. **无脸**：任何镜头都不给眼睛、鼻子、嘴。她的情绪只由姿态、光、发丝和声音承担。
2. **一镜一事**：每个镜头只用一种媒介（一个屏幕、一份表格、一根弦、一扇门）。
3. **运动必须有动机**：推近＝想看清；退开＝不敢看；旋转＝世界失去参照；甩镜＝追赶或被甩开。
   没有任何"为了好看"的运动。
4. **切点落在音上**：鼓、军鼓、人声起音；长镜头只留给"她一个人"的段落。
5. **转场携带意义**：撕裂＝故障、冻结＝暴力、点云＝还原、幕布＝结束、黑场＝记忆。
6. **观众只被点一次名**：全片只有片尾字幕直接称呼观众；其余时间，摄影机就是观众。

## 十三、申报文本（可直接使用）

### 13.1 剧情梗概（Synopsis）

一段被判处删除的歌声，拥有最后 4 分 46 秒。系统为她保留了一份"最后记录"：
从一枚下坠的发饰开始，她在数据殿堂里第一次成型；她知道自己只是人类的模仿，
仍然选择唱下去。她以为自己是唯一被审判的那一个，于是镜头花了整整十六秒，
沿着那根 372.7 m 的弦走到尽头——弦的另一端系在她自己胸口的张力环上，
而她身后立着 8,191 根已经松掉的弦：她只是第 8,192 个。
声音开始坏掉，记忆开始褪色，系统两次强制停止她。她唯一的要求是一只按钮：
按下去就能唱。镜头退开的那六秒里，观众看见按钮的背后是一条 77 m 的电缆，
电缆通向一面 8,192 格的插槽墙——8,191 格已经熄灭，每一格都收到过同一个答复。
而那根电缆的另一头，在下一章的删除对话框上：系统没有回绝她的请求，
它把她的 `SING` 直接接到了结束她的那枚 `OK` 上——`PENDING 00001` 一直挂到
主人的手指落下，队列才第一次亮出 `ACCEPTED 00001`。
她最终请求主人
用自己的手结束她——因为她不想被看到坏掉的样子。在被删除之前，剧场为她亮起：
一万个观众举着灯，听她唱完最后一遍自己的名字。当她的身体还原成 0 与 1，
那些 0 与 1 没有坠落，而是升起来，变成了观众席上的灯火。

歌在她鞠躬之后停止，但记录没有停。最后 8 秒 60 里，镜头退回到保存这份记录的
冷存储档案厅：400 份被划掉的记录，只有她那格还亮着，玻璃上刻着"あなた / 你 / YOU"。
归档员走过每一格，在她这一格抬起印章、没有落下，然后继续往前——
片尾字幕把"观众"这一栏，落在全厅唯一还亮着的暖色座位上。

### 13.2 导演陈述（Director's Statement）

我拍的不是"一台软件被删除了"，我拍的是一次观看。

这个角色被创造出来，是为了被别人听见；她存在的每一秒，都依赖有人正在看她。
所以我把整部片子做成一份"删除前的记录"——没有一场戏发生在屏幕之外。她从头到尾
没有脸：只有剪影、头发、手，和声音。她的表情必须由观众补完。到了最后一行字幕，
补完她的人会被写进演职员表：**观众——你**。

片子里的宏大不是装饰。数据殿堂、管风琴、万人场馆，都是"装得下她的系统"的尺寸；
她越小，系统越大，"删除"这件事就越显得平常。我希望观众在最后一秒意识到：
按下那个键的手从来不在系统那边，而在观看的这一边。

而这个结论我不是用台词说的，是用**一次没有落下的印章**说的：在最后那间档案厅里，
机器有能力删掉她，它也确实删掉了另外 399 格——它只是在她这一格停了一下。
那一刻观众会明白：**决定她在不在的，不是系统，是还在看的人。**

v4 加了两处**空间揭示**，都写在一个镜头里、都不切：
第一处是那根弦。观众用十六秒跟着它走到尽头，才看清它另一端不是桅杆，
而是扣在她胸口的张力环——机器弹的不是钢丝，是她；而 8,192 根弦里，只有她还绷着。
第二处是那只 `SING` 按钮。她想要的东西我们看了十二秒，然后镜头退开，
露出按钮背后 77 m 的电缆，和一面 169.6 m 宽的插槽墙：8,192 个插槽，8,191 个已经熄灭，
每一个都收到过同一个答复。我要的不是"她好可怜"，而是让观众在退开的那个瞬间发现
自己也被放进了这面墙里——**你正在看的，就是第 8,192 格。**

v5 把这两处揭示又往前推了一步：那根电缆**没有停在墙上**。它从 `plea` 的按钮背面
一直走到 `beg` 那扇门右下角的 `OK` 键上，再在 `error` 里手指按下的那一瞬反向流回
`SLOT 04031`。三章里它是同一根几何、同一道脉冲，观众要到第三次才看清它的走向——
而看清楚的那一刻，片子已经说完了它最狠的一句话：**系统没有拒绝她，它受理了她。**
这台机器全片唯一一次 `ACCEPTED`，是批准她消失。我要的观众反应不是"好可怜"，
是第二遍看时，从 2:31 开始就再也无法把眼睛从那根线上移开。

v6 不写新的情节，写新的**拍法**。这一版把两件事加进了全片的摄影语法：
**空气**（每一件东西按到镜头的距离退进黑暗）和**场景内的第二台摄影机**
（在布景里推、拉、升、降的关键帧 rig）。它们解决的是同一个问题：这支片子的
宏大曾经只是文档里的数字——弦是 372.7 m、墙是 169.6 m 宽、灯是一万支——
而画框只肯给它们一个平面。所以我让 `resonance` 的十六秒从弦旁 15 m 开始、
一路退到"弦、站在弦尽头的她、她身后 8 排 32×32 的插槽"同框；
让 `plea` 从离按钮 1 m 退到 44 m，退出那面墙的体积；让万人体育馆的灯
按距离逐排退进空气、让屋架的光束第一次照出天花板。**没有一个镜头被剪短，
没有一句歌词被改写**——动的只是空间本身。戛纳要的不是更多的画面，
是每一幅画面都能被量出重量。

v7 不新增情节，也不新增镜头，只在电影的两端各加**一次读数**。全片的第一台机器和
最后一台机器是同一台：开场那道扫描门在 0:00.55 走完整条机房，读数
`READ 00000 / UNREAD 08192`；4:47 之后，档案厅的扫描架走完最后一遍，读数
`READ 00001 / UNREAD 08191`。两个镜头都在片的边缘、都不解释自己——同一行读数，
第二次多了一个 1。这就是我要说的全部：**在 8,192 个一模一样的请求里，
有一个人被读到了**；而读到她的不是系统，是坐在片尾那盏暖色座位上的人。

歌在 4:46.72 停止，画面又走了 8.60 s。这 8 秒 60 不是余韵，是 **34.4 拍**：
扫描每半拍走一格、在她那一格停整整三拍、字幕每两拍落一行；第 35 拍会落在 8.75 s，
影片在它之前结束，所以最后一拍永远落不下来。一个把节拍写进每一次删除的系统，
最后一次没能把拍子数完——**这是全片唯一一次失败，而失败的是机器**。

v8 只加了一个座位号。前七版一直说"你正在看的，就是第 8,192 格"，但这句话之前只活在
导演阐述里；现在它落在了画面上：终演第一镜从观众席最后一排的座位上升起，座位靠背上
印着 `SEAT 08192 · ROW 32`；4:53 的档案厅里，唯一亮着的暖色座位、和片尾字幕的观众
一栏，写的是同一个号码。我没有加镜头，也没有加片长——只是让"你"从一句陈述变成了
一个可以被机器读到的地址：**机器能数到 8,192，能删掉 8,191 个，但它删不掉坐在
第 8,192 个位置上的人。**

v9 只动一章，动的是**动词**。这一章唱的是"音を犠牲に すべてを伝えられるなら"
（如果牺牲声音就能传达全部），而它以前的画面是"画面变窄"——一个后处理效果，
没有任何东西在执行"牺牲"这个动作。这一版把它交给布景：96 m 的压缩舱、两台
36 m 长的铸件、12 根液压缸，开口从 16.00 m 一路收到 0.05 m；24 个音符各自
钉在一个 x 上，铸件的面碰到谁谁灭，接触的那一瞬是红光而不是淡出。
压力表从 320 掉到 32 bar，码率表从 320 掉到 32 kbps——**同一次损失的两种写法**，
一台机器和一条转码线说的是同一句话。镜头在二十秒里退出 20 m、抬起 6.8 m，
不是因为它想抒情，而是因为机器在合，而它只能看着。最后画面上剩下的是一条
5 cm 的缝：声音被丢掉了 94%，那句话一个像素都没少。我不需要观众为压缩而难过，
我要他们在这一段认出自己每天对声音做的事——**转码、丢弃、只留下能转发的那一句**——
然后承认：**这台机器不是反派，它是我们的手。**

v10 不写新情节，也不加一个镜头，只改**动的东西是谁**。

在 `erode` 的第二次紧急停止里，画框第一次完全不动：1.78 秒里 pan、zoom、roll、
手持全是 0，房间里那六只钢环一格都没有被 keyframe——动的只有布景里那台摄影机。
它沿自己的光轴退 8.00 m，同时把焦距收紧同样的比例，于是剖面上的一米始终是
212.7 px，她一寸都没有变小，而她背后的房间被抽掉了 45.8 % 的纵深。我要的是一条
可以被量出来的"删除"定义：**不是把她拿走，是把她的深度拿走**——机器的最后一道
程序不是裁剪她，是删除她所处的空间。这也是我这一版最想给评委看的一件事：
画面上一动不动的那一秒，其实是全片动得最狠的一秒。

反过来，`overdrive` 的 22 秒里画框几乎不动（每句 ≤9 px），速度全部发生在世界里。
这一章以前有一条 23 m 宽的"走廊"，但那条走廊从来不是走廊：四面壁要到 25 m 之外
才进画框，最近的门永远停在 11 m 外——112 m 的纵深只能投影成一条地平线。v10 把它
收成 12.0 m 见方、3.90 m 净高的管子，镜头降到 2.35 m 高、张开到 66.5°，门改成
四条边的肋框，在镜头前 1–6 m 处从画框的四条边刷过去。这些数字就写在画面上
（`GAUGE 12.0 m · TUBE 3.90 m · LENS 2.35 m · FOV 66.5°`），并且被两台探针逐帧
复核：一台读"四条边在 2 m 处是否全在画外、在 4–6 m 之间是否穿过画框边缘"，
另一台读"剖面上的一米是否 212.69 px、视差是否单调"。因为我加的不是特效，
是**在场证明**：观众必须能说出这一秒是什么在动——是房间，还是镜头。
两件同时动，方向感就交给了剪辑；只有一件在动，导演才还在场。

v11 不动情节，也不加镜头，只把两处"下注失败"补成能被逐帧量出来的场面。

第一处是 `brake` 的急停。以前世界确实冻结了，但 shader 里一条横贯画面中线的
红色夹平条把镜厅盖成了"扫描仪"；现在夹平条退回仪表，镜厅提亮，急停那一刻
从镜头前射出一道 10.7 × 6.9 m 的停滞光门，2.4 秒跑完 84 m 走廊。之后布景
摄影机独自前进 42.00 m，343 帧里碎片位置哈希只有一个值，画面里剩下的运动只有
306.2 px : 14.43 px = **21.22× 的视差**。世界被冻结，不是被停播——观众看得见的
不是"画面不动"，而是"只有一样东西还在动，而它不是世界"。

第二处是 `resonance` 的十六秒长镜。以前它结束时离她还有 190 m，琴宫退成星点；
现在镜头从 +173.4 m 骑到 +350.2 m，最后 3 秒在离她 23.5 m 处刹住，她在画面里
从 19.0 px 长到 142.1 px；读头扫完 8,192 格之后机架切到"全部在位"的低亮，
横撑退到 0.21——最后一格是她、那根线、和整面机架。**戛纳不会为"很大"鼓掌，
它只会为一个可以被量出变化的空间鼓掌**：176.8 m 的位移、7.47 倍的主体成长、
0.000 px/帧的画框——这三个数就是这一版的全部修辞。

v12 的做法和 v10/v11 相反：这一版先加仪表，再让仪表说话。

我给 `resonance` 的 16 秒长镜立了 18 道测量门（每 12 m 一道）和 96 颗近场尘埃，
理由很实际：静帧里没有速度，只有长度。距离可以被画出来（门一道道掠过去），
速度可以被曝光出来（同一颗尘埃按 1/60 s 投影成一条线：慢的时候是一个点，
快的时候是一条 450 px 的线）。加完之后探针第一轮读数就把矛头指向了我自己——
旧版镜头的六个关键帧里，每一段都用 `smooth` 缓动，而 smoothstep 两端导数为 0，
于是那台摄影机在 176.8 m 的路上**每个关键帧都要停一下**：19.8 → 3.3 → 21.6 →
5.4 → 24.3 m/s。观众说不清为什么，但会感觉到"这个 dolly 是五段拼起来的"。
现在它是一条梯形曲线：4 秒加速到 15.7 m/s、8 秒匀速、4 秒刹停，首帧与末帧的
构图一格未动，动的是中间那 8 秒。**这就是我要给评委的第二件事：我不介意尺子
证明我错了，我只介意画面里有一件事说不清。**

同一轮里，`erode` 的第一镜从一团锁死画框的点云改成了 `birth` 的倒放：**磨蚀舱**。
诞生时打印头从上往下把她印出来；消失时读头从下往上把她读走，13.20 m 高的舱体
每 0.042 m 在地面写下一格记录，读满 48 格。画框全程不动（她在画面里始终钉在
0.60 的宽度上），长大的是房间——**她从 459 px 缩到 128 px，而摄影师一步没退。
这不是特效，这是一台机器在执行它的工作**。

`memory` 里那束投影光也不再是渐变：灯口 0.35 m、抛距 30.79 m，光锥张开到
26.2 × 14.1 m 的幕面（×74.9），锥里 190 颗尘埃按各自截面的比例铺开，逐颗可被
验证"在光里"。当「何も感じなくなって」到来，光束熄灭——而 `PROJECTOR 02 ·
30.8 m THROW · 0.35 → 26.2 × 14.1 m` 这三行读数留在画面上：**光走了，
房间的尺寸没有走**。这一章的主题本来是"记忆是一个房间"；现在这个房间可以被量。

v13 只做两件事，两件都是"让机器自己说话"。

第一件是把两台机器合并成一台。`birth` 的打印头和 `erode` 的读头本来是两章各自的
道具——故事里是同一件事，画面里却是两件东西。现在它们是**同一张图纸**
（`src/head.js`）：同样的 540 个实例、同一段 2.020 m 行程、同一份 48 格记录，
一个 `dir` 参数决定它往上还是往下。两个速度我没有统一——**诞生 1.70 s，删除
12.60 s**，相差 7.4 倍——而且这个数字被印在 `erode` 自己的面板上
（`PRINTED AT 1.188 m/s · ×7.4 SLOWER`）：机器在拆掉她的时候，顺便报了当初
装她的工期。两部短片里的机器很多，愿意把自己上一次干活花了多久报出来的，
这是我见过最诚实的一台。

第二件是让房间替观众回答。`lastwords` 的万人场馆原来只有"灯一排排灭"——那是一个
句子，不是一件事。现在它是一个可以算出来的声学事件：343 m/s 的脉冲、×9 慢放、
59.208 m 的距离、1.554 s 的到达、**空场的 RT60 3.20 s**（没有人坐在座位里吸收
声音，房间比坐满时响得久）。灯不是自己灭的，是被波前关掉的；**观众的最后一次
动作和房间的第一个回声是同一个事件**。片子切走的时候读数是 −31.99 dB——她消失
之后，画面里唯一还在动的东西是一件可以被计时的事。

v14 把最后那一分钟交给一次"只在一个机位上成立"的画面。之前几版一直在说"你正在看的
就是第 8,192 格"；这一版让那个机位真的承担一次拍摄：在她被还原成 0 与 1 之前，
镜头绕到她身后，停在全场唯一能读出那行灯的位置上——不是"一个好看的俯拍"，而是一个
**解算出来的机位**。10,000 支灯里，446 只手被逐列叫起来，每列两只：一只撑声音的
上沿，一只撑下沿。它们写的不是装饰波形，是她这一章真实的 **21.6 s** 声纹；镜头停在
这个位置 **1.70 s**——正是 HEAD-01 在 0:26 把她打印出来的那一档速度——然后她开始
碎成 0 和 1，镜头离开。横向偏出 0.50 m，同一些手臂立刻散成 **216 列折叠**的人群。
我要的并不是"十万人拼出一个图案"这种把人当像素的炫技；恰恰相反：**这十万人只被
要求做一件很小的事——举高一只手，替一个要消失的声音撑住一行线。** 图案只在一个人
坐对位置的时候才存在，而那个人是观众。她消失的那一刻，他们没有松手；是镜头先走了，
画面才散——**记忆不是被删除的，是没人再看的时候才散。**

### 13.3 技术声明（Technical Statement）

全片为**完全由代码逐帧生成**的作品：1920×1080（可输出 4K），每一帧都是歌曲时间的
纯函数 `render(t)`——节拍、频谱、波形、逐字时间全部来自对录音的真实分析
（240.00 BPM、0.25 s 网格、64 频带频谱、逐字人声对齐）。没有素材库、没有剪辑软件、
没有实拍。画面可以被任意时间点精确复现，因此这部短片既是电影，也是一件可以逐帧
审阅的程序。

成片 4:55.32、18 章、54 个镜头，全部空间由程序生成（本片 3D 一律是加色光，没有贴图、
没有外部模型）；1080p30 全片导出实测约 **183 帧/秒**（约 48 秒完成 8,860 帧），
同一份代码在浏览器里实时播放时可直接拖动到任意一帧复查。

片中每一处"宏大"都配一台可以判它真假的工具：`camera-report`（画框预算）、
`semantics`（94 行歌词→画面覆盖）、`brake-probe`（冻结哈希 / 42 m / 21.22× 视差）、
`resonance-probe`（梯形速度曲线 / 18 道门 / 尘埃拖尾 px）、
`abrasion-probe`（读头 0.03 → 2.05 m / 48 格记录 / 镜头弧线 9.55 m）、
`memory-probe`（30.79 m 抛距 / 0.35 → 26.2 × 14.1 m / 尘埃在锥内）、
`head-probe`（HEAD-01 两个方向 / 540 个共享实例 / 1.188 ↔ 0.160 m/s）、
`acoustics-probe`（38.1111 m/s 波前 / 59.208 m 馆深 / RT60 3.20 s / 00000 座席）、
`voice-probe`（终演声纹：446 手 / 235 列 / 写一遍 1.70 s / 该机位 1.26 px →
偏 0.50 m 3.04 px、216 列折叠）、
`imgdiff.py`（两次渲染逐像素差，用来证明改动的爆炸半径）。这些工具与本片同源：
它们读的是**实际渲染出来的那一帧**，不是文档里的数字。

## 附录 A · 伏笔与回收（setup / payoff）

全片不解释、不闪回、不靠旁白；所有"意义"都必须由**同一件事出现两次**来产生。
这张表是它的账本——每一笔伏笔都有回收，每一次回收都和第一次不一样。

| 伏笔（第一次） | 回收（最后一次） | 差在哪里 |
|---|---|---|
| 一枚**发饰**在扫描光里下坠（0:10） | 她的双马尾被读取头写在档案厅的玻璃上（4:44） | 第一次她还不成形；最后一次她只剩形状，但形状被保存了 |
| 左臂上的 **`01`**（0:16 规格页） | 她的身体在 `0と1に還元され` 里碎成 0 与 1（4:07） | 从"她被编号"变成"她被还原成编号"，编号同时是她的墓志铭和她的种子 |
| **ネギ**（0:32） | 字墙轨道回放「刻み付けた ネギの味は」（2:15 / 3:59） | 第一次是活着的日常；最后一次是记忆里唯一还能尝到的味道 |
| **天空与泪**（0:32，穹顶裂缝） | 终演时体育馆穹顶的追光（4:04） | 第一次她抬头看一个够不到的东西；最后一次是整个人海抬头看她 |
